# Contributing

Contributions are welcome.

## Before opening a pull request

1. Keep changes focused and small.
2. Preserve the package's lightweight SwiftUI API.
3. Avoid third-party dependencies unless clearly necessary.
4. Consider loading, retry, cancellation, and end-of-data behavior.
5. Add or update tests for pagination logic when appropriate.
6. Run:

```bash
swift build
swift test
```

By contributing, you agree that your contributions will be licensed under this repository's MIT License.
