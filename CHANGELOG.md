# Changelog

All notable changes to this project will be documented here.

## Unreleased

### Added

- Reusable SwiftUI paginated list.
- Initial async loading.
- Threshold-based page prefetching.
- End-of-list loading.
- Duplicate-request prevention.
- Retry handling for failed requests.
- Load cancellation when the view disappears.
- Custom empty content.
- Configurable retry label and row spacing.
- iOS and macOS support.
- Swift Package Manager support.
- Unit tests and examples.
